# java-racingcar-precourse

## 구현 기능
- [X] 자동차 이름을 입력받아 자동차 객체를 생성
- [X] 1회마다 자동차를 전진 or 멈춤 

    0 - 9까지의 랜덤값을 받은 후 4 이상일 시 전진
- [X] 차수별 실행 결과 출력
- [ ] 최종 우승자 판별

---
## 예외 처리
- [x] 자동차 이름에 영문자가 아닌문자가 입력되었을때
- [x] 자동차 이름에 중복이 발생했을 때
- [x] 자동차 이름, 시행횟수가 빈칸으로 입력되었을때
- [X] 자동차 이름의 길이가 5자를 넘어갈때
- [ ] 시도 횟수로 너무 큰 값(500 이상)이 입력되었을 때
- [ ] 시도 횟수로 숫자가 아닌 문자 or 0이나 음수가 입력되었을 때

---
## 전제 조건
- 자동차 이름의 문자는 영문자만 사용 가능하다
- 입력시 발생하는 빈칸 (eg. "우테코1, 우테코2" 에서 쉼표 뒤 빈칸)은 무시한다
- 자동차 경주 트랙의 최대 길이를 100으로 설정하고 시도 중 100에 도착한 차량이 발생하면 우승자를 선정한다

## 클래스 설명

### [Common]

- `RacingGameStrategy` : 경기 규칙에서 사용하는 상수들을 모아놓은 객체
- `Validator` : 입력값을 검증할 때 사용하는 상수들을 모아놓은 객체
- 

- `ErrorMessage` : 에러발생시 사용되는 메세지들을 상수화 하여 모아놓은 객체
- `ViewMessage` : `Output`에서 사용되는 메세지들을 상수화 하여 모아놓은 객체


### [Controller]

- `RacingController` : 자동차 레이싱 동작 전체를 관리하는 클래스


### [Model]

- `RaceParticipants` : 경주할 자동차 객체의 `List`를 감싼 일급컬렉션 객체


- `Car` : 자동차의 상태(이름, 위치)와 행위(전진)를 가지는 객체. 생성 시 이름 유효성 검사를 수행
- `CarDto` : `Car`의 데이터 전송 객체


### [Service]

- `Racing` : 자동차 경주를 진행하는 인터페이스
- `RacingImpl` : `Racing` 객체의 구현체


### [Util]

- `InputValidator` : 입력값 유효성 검사


### [View]

- `Input` : 사용자의 입력을 받는 객체
- `Output` : 프로그램의 출력을 담당하는 객체

`Application` : 프로그램을 실행하는 객체
