# java-racingcar-precourse

## 구현 기능
- [X] 자동차 이름을 입력받아 자동차 객체를 생성
- [ ] 1회마다 자동차를 전진 or 멈춤 

    0 - 9까지의 랜덤값을 받은 후 4 이상일 시 전진
- [ ] 차수별 실행 결과 출력
- [ ] 최종 우승자 판별

---
## 예외 처리
- [x] 자동차 이름에 영문자가 아닌문자가 입력되었을때
- [x] 자동차 이름에 중복이 발생했을 때
- [x] 자동차 이름, 시행횟수가 빈칸으로 입력되었을때
- [X] 자동차 이름의 길이가 5자를 넘어갈때

---
## 전제 조건
- 자동차 이름의 문자는 영문자만 사용 가능하다
- 입력시 발생하는 빈칸 (eg. "우테코1, 우테코2" 에서 쉼표 뒤 빈칸)은 무시한다

## 클래스 설명

### [Common]

- `Validator` : 입력값을 검증할 때 사용하는 상수들을 모아놓은 객체


- `ErrorMessage` : 에러발생시 사용되는 메세지들을 상수화 하여 모아놓은 객체
- `ViewMessage` : Output에서 사용되는 메세지들을 상수화 하여 모아놓은 객체


### [Controller]

- `RacingController` : 자동차 레이싱 동작 전체를 관리하는 클래스
