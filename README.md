# java-racingcar-precourse

## 구현 기능
- [ ] 자동차 이름을 입력받아 자동차 객체를 생성
- [ ] 1회마다 자동차를 전진 or 멈춤 

    0 - 9까지의 랜덤값을 받은 후 4 이상일 시 전진
- [ ] 차수별 실행 결과 출력
- [ ] 최종 우승자 판별

---
## 예외 처리
- [ ] 자동차 이름구분이 잘못 되었을 때
- [ ] 자동차 이름의 길이가 5자를 넘어갈때
- [ ] 자동차 이름에 중복이 발생했을 때


---
## 전제 조건
- 자동차 이름에 문자는 숫자를 포함해 다 사용가능하다
- 자동차 이름에 빈칸은 사용 불가능하다
- 입력시 발생하는 빈칸 (eg. "우테코1, 우테코2" 에서 쉼표 뒤 빈칸)은 무시한다
